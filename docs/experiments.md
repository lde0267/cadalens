# 실험 기록 — 임야 형질변경 zero-shot 스크리닝

칩 생성 방식과 모델 사용 방식을 단계적으로 바꿔가며 검증셋 150개로 정량 평가.
형질변경 = positive, `p_forest < τ` 면 flag, τ 스윕으로 P/R/F1.

> 실험 코드: `02_experiments/image_method/{classify_wholeimage,classify_interior,classify_densepatch}.py`
> (문서 약칭 v1 = whole-image / A1 = 필지 내부만 / C2 = 패치별 dense). 운영 프로파일: `03_pipeline/configs/imya_*.json`
> (재구조화 2026-09 때 `data/experiments/` 산출물·fig 는 폐기, 코드로 재생성).

**검증셋**: 임야 428 중 면적 5분위 층화표집 150개 육안 라벨 → 형질변경 88 / 임야 62
(등록 임야의 59%가 실제 형질변경).

---

## 1. 필지만 뽑아서 (mask 칩) — 검정이 추론에 사용됨

- 칩: 필지 bbox → 폴리곤 밖 검정(0) → 정사각 패딩 → 224
- 문제: 224 안에서 실제 필지 픽셀 23~70%뿐. ViT가 검정 패치도 토큰으로 만들어 임베딩에 섞음 → 어둡게 편향, 얇은 필지는 "선/도로"로 오인
- 결과 (v1 CLS · v1 프롬프트):

  | τ | P | R | F1 |
  |---|---|---|---|
  | 0.50 (기본) | 0.95 | 0.20 | 0.34 |
  | 0.85 | 0.88 | 0.56 | 0.68 |
  | 0.95 | 0.75 | 0.84 | 0.79 |

- **부수 발견 — τ가 지배적 레버.** 기본 0.5는 재현율 0.2로 무의미. `p_forest` 자체엔 신호가 있어 τ를 올리면 F1이 0.79까지 상승

## 2. 전체 영상으로 (context 칩) — 필지 아닌 부분이 영향

- 칩: 필지 중심 넓은 창(이웃 마을·도로) + 폴리곤 외곽선
- 문제: 모델이 프레임 전체를 설명 → 옆에 마을 있으면 "주거지" → 순수 임야도 오탐
- 결과: 428필지 중 182개(43%) flag (mask는 63개). 정밀도 붕괴
- 1과의 차이: 검정 대신 실제 이웃 → 검정 편향은 사라지나 이웃이 판정을 오염. 반대 방향 실패

## 3. 모델 구조 변형 (A1: 토큰 드롭) — 검정이 추론에 안 쓰이도록

- 변형: patchify 직후 폴리곤 밖 패치 토큰을 시퀀스에서 제거 → CLS가 내부 패치만 요약
- 결과 (mask · v1 프롬프트): best F1 **0.74** — 1의 whole-image(0.79)보다 나쁨
- 이유:
  - 토큰 4~25개는 CLS pooling이 학습된 적 없는 분포(OOD) → 노이지
  - 필지 옆 도로·건물 맥락은 형질변경 탐지엔 오염이 아니라 신호인데 버림
  - 남은 패치의 절반이 경계 걸침이라 어차피 순수한 "필지 내부"가 아님
- 1·2와의 차이: 검정도 이웃 오염도 없앴지만 "필지만 정확히 보기"가 정보를 줄여 성능 하락
  → 적당히 필지에 맞춘 프레임을 통째로 쓰는 게 낫다

## 4. 필지 내에서도 지배적인 영역이 존재 (C2)

- 관찰: 이미지 임베딩은 패치들의 (attention) 평균에 가까움. 필지 70%가 숲이면 도로·나지 30%가 있어도 "대체로 숲"
- 실물 — 산21-47임: 포장도로가 필지 관통, `closest_neg = "a paved road"` 인데 `p_forest = 0.99`.
  forest vs not-forest 코사인 마진 0.045, `logit_scale ≈ 100` 이 0.99/0.01 로 증폭
- 대응(C2): 마지막 블록 구조 변형(MaskCLIP)으로 패치마다 개별 점수 → "built 패치 비율"로 집계
- 결과 (mask · v1 프롬프트): F1 **0.13** (사망). 패치 하나의 코사인도 좁게 뭉쳐 patch별 점수가 0.5를 못 넘음
  (built_frac 최댓값 0.22 — 태양광 필지조차). ViT-L/14(256패치)로도 안 살아남
- 3과의 차이: 3은 "밖을 버리는" 변형, 4는 "안을 쪼개는" 변형. 둘 다 zero-shot 코사인의 압축 한계에 막힘

## 5. 종합 — 프롬프트 특화(v2) + real 칩

- **v2 프롬프트**: 일반 명사구 대신 형질변경 유형별 서술문
  (`"a patch of bare soil with tree stumps where forest was cleared"`,
  `"grave mounds on a cleared hillside"`,
  `"a new dirt or paved road cut through forest"` …)
- **real 칩**: 필지 bbox를 224에 꽉 채움(정사각패딩·검정 없음), 밖도 원본 정사영상, alpha = 폴리곤 1/0
- 결과 (best F1 지점):

  | 구성 | best τ | P | R | F1 |
  |---|---|---|---|---|
  | v1 CLS · v1 · mask | 0.95 | 0.75 | 0.84 | 0.79 |
  | v1 CLS · v2 · mask | 0.80 | 0.70 | 0.84 | 0.76 |
  | **v1 CLS · v2 · real** | **0.85** | **0.78** | **0.82** | **0.80** |
  | A1 토큰드롭 · v2 · real | 0.95 | 0.61 | 0.94 | 0.74 |

- real 칩은 **v2 프롬프트와 함께일 때만 이득** (v1 프롬프트엔 중립~손해)
- A1(토큰드롭)은 real 칩에서도 whole-image CLS보다 못함 — 3의 결론 재확인

## 6. mask 칩 프롬프트 재설계 — 통제 ablation

- 발표는 mask 칩 채택. 5·real 은 real-fit 이라 mask 용 프롬프트를 데이터로 다시 설계.
- 고정: 칩(mask 428)·백본(B/32)·whole-image CLS·템플릿 4종. **프롬프트 문구만 교체.**
- 평가: 손라벨 150 → dev/test 75/75 (면적 5분위 × 라벨 층화, seed 42).
  dev 에서 τ 스윕 → F1 최대 평탄대 중앙 τ\*, test 는 τ\* 로 1회 채점.
- 세트: A=v1(일반명사) · B=v2(서술형) · C=mask특화 서술형 · C2=C−초지 · **D=실제 산지전용 빈발유형
  (태양광·주택·창고·도로·개간·조성나지·온실·묘지·야적), 오탐 최다 도로 명시 유지** · D2=D 자연어꼬리 제거.
- 결과 (test F1, positive=형질변경):

  | set | dev τ\* | test P | test R | test F1 | ΔF1 vs A | 판정불가밴드(428) |
  |---|---|---|---|---|---|---|
  | **A · v1** | 0.95 | 0.77 | 0.76 | **0.764** | — | 51 % |
  | B · v2 | 0.79 | 0.72 | 0.80 | 0.758 | −0.006 | 19 % |
  | C · mask특화 | 0.96 | 0.68 | 0.84 | 0.752 | −0.012 | 35 % |
  | C2 · C−초지 | 0.98 | 0.66 | 0.82 | 0.733 | −0.031 | 42 % |
  | D · 산지전용 빈발 | 0.99 | 0.64 | 0.80 | 0.713 | −0.051 | 43 % |
  | D2 · D 평평화 | 0.99 | 0.71 | 0.80 | 0.750 | −0.014 | 55 % |

- 여섯 세트의 **자체최적 F1 은 0.75~0.79** — 분할 노이즈(±0.02) 안 동률. 어느 세트도 A 대비 +0.02 미달.
- Set D: negative 를 실제 빈발 산지전용 유형으로 좁혀도 F1 안 오름. 자연어로 쓰면 겨울 임야를 흡인(FP↑),
  평평하게 쓰면(D2) 분리 붕괴(회색지대 55 %). 단, C 의 좁힌 도로문구
  `"a wide paved road or graded dirt track cutting across the hillside"` 는 v1 최다 오탐원 정리에 유효.

### 6b. context 칩 + 한국 산림특성 positive (Set E)

- 칩만 `01_preprocess/chips/37714092_context` (필지 중심 넓은 창 + 외곽선, 필지가 프레임의 중앙값 14 %).
- positive 를 **우리나라 산림특성**으로: 급경사 산지, 침엽(소나무·잣·낙엽송)+낙엽활엽(참나무류) 혼효림,
  겨울 갈색 참나무 + 상록 소나무, 조림지 줄심기, 임도·방화선 허용.

  | set | 구성 | test P | test R | test F1 | ΔvsA | 안정성 |
  |---|---|---|---|---|---|---|
  | E0 | context + v1 | 0.69 | 0.78 | 0.729 | −0.035 | 안정 |
  | E1 | context + 한국산림 pos + 산지전용 neg | 0.62 | 0.91 | 0.739 | −0.025 | 불안정 |
  | E2 | context + 일반 pos + 산지전용 neg | 0.63 | 0.84 | 0.724 | −0.040 | 안정 |
  | **E3** | context + 한국산림 pos + v1 넓은 neg | 0.75 | 0.84 | **0.792** | **+0.028** | 안정 |

- **한국 산림특성 positive 가 context 에서 실효**: neg 고정하고 pos 만 일반→한국산림 → E0 0.729 → E3 0.792
  (+0.063). context 프레임의 86 %가 주변 산이라 "steep Korean mountain, mixed pine and brown oak" 가
  지배 장면과 정합. (mask 에선 필지 표면만이라 안 먹혔음 — §6 과 대비.)
- "산지전용 빈발유형" neg 는 context 에서 역효과: 프레임 내 이웃(집·도로·나지)에 걸려 337/428 flag, τ 불안정.
- **E3 는 τ 0.50~0.94 전 구간에서 test F1 0.75~0.79** (mask A 는 τ 0.95 근처만). 판정불가밴드 5 %.
- 단 정밀도 0.75 (61 % flag) → **고재현 1차 스크리닝 프로파일**로 별도 채택 후보 (`02_experiments/prompt_ablation/prompt_sets/set_e3.json`).

### 6c. A1(모델이 필지 패치만) + 한국 산림특성 pos

- `02_experiments/image_method/classify_interior.py` (A1) : 폴리곤 밖 패치토큰 드롭 → CLS 가 필지 내부만 요약. mask 칩.

  | set | test P | test R | test F1 | ΔvsA | 안정 |
  |---|---|---|---|---|---|
  | A1 + v1 | 0.69 | 0.73 | 0.710 | −0.054 | 안정 |
  | A1 + C (mask 서술) | 0.75 | 0.73 | 0.742 | −0.022 | 안정 |
  | **A1 + E1 (한국산림 pos + 산지전용 neg)** | 0.70 | **0.98** | **0.815** | **+0.051** | 안정 |
  | A1 + E3 (한국산림 pos + v1 넓은 neg) | 0.64 | 0.87 | 0.736 | −0.028 | 불안정 |

- **A1 + E1 = 전 실험 통틀어 최고 F1 0.815, recall 0.978.** 필지 내부 패치만 볼 때는 pos·neg 가
  **둘 다 구체적**이어야 효과 (한국형 임상 텍스처 vs 태양광·건물·벌채나지 텍스처가 선명히 갈림).
  일반 pos(A1+v1) 는 F1 0.71 로 최저권. 정밀도 0.70 → 고재현 스크리닝용.

### 6d. 폴리곤 밖 채움: 검정 vs 다른 값

- `02_experiments/image_method/classify_wholeimage.py --fill {black,mean,gray,inpaint}`. v1 프롬프트 고정.

  | fill | test P | test R | test F1 | ΔvsA | 밴드 |
  |---|---|---|---|---|---|
  | **black** (현행) | 0.77 | 0.76 | 0.764 | — | 51 % |
  | **mean** (내부 평균색) | **0.85** | 0.76 | **0.800** | **+0.036** | 46 % |
  | gray (상수 회색) | 0.69 | 0.82 | 0.748 | −0.016 | 47 % |
  | inpaint (텍스처 연장) | 0.84 | 0.71 | 0.771 | +0.007 | 32 % |

- **내부 평균색 채움 > 검정** (F1 +0.036, 정밀도 0.77→0.85, 안정, 한 줄 변경). 검정은 어두운 편향 +
  얇은 필지를 "도로"로 오인 (`a paved road` attractor 99→47). 프레임 85 %를 필지 자기색으로 채우면
  임상 필지 = 녹색 프레임, 전환 필지 = 갈색 프레임.
- **상수 회색은 검정보다 나쁨** — 균일 회색이 "평탄 나지"로 읽혀 임상 필지를 negative 로 끌어당김.
  → 채움은 **필지 자기 색**을 담아야 이득.

### 6e. 종합

- mask whole-image 에서 **프롬프트 문구는 레버가 아님** (A~D2 전부 ±0.02). 실제 레버 3개:
  **① 폴리곤 밖 채움(black→mean, +0.036)**, **② 인코딩(A1·context)**, **③ 한국 산림특성 pos**
  (A1·context 와 결합 시 +0.05~0.06). 셋 다 프롬프트 세트 교체가 아니라 파이프라인 구조 변경.
- 프로파일 분리: **정밀 판정** = mask + mean-fill + v1 (F1 0.80, P 0.85, τ≈0.93) ·
  **고재현 스크리닝** = A1 + 한국산림 pos + 산지전용 neg (F1 0.82, R 0.98, τ≈0.83).
- **서술형 무이득**: mask 칩은 필지 표면만 → 장면·재질 서술이 검정편향·형상신호와 경합, 정밀도 하락.
- 서술형 부수효과: v2 는 판정불가밴드를 51 %→19 % 로 축소. C 의 관통도로 특화문구는 v1 최다 오탐원
  `"a paved road"` 를 정리 (attractor 34→2).
- **확정: v1 유지** (`03_pipeline/prompts/imya_forest.json`), τ\*≈0.95. 상세 = `02_experiments/prompt_ablation/ANALYSIS.md`. 운영 프로파일은 `03_pipeline/configs/imya_*.json`.

## 결론

| 축 | 관찰 |
|---|---|
| 임계값 τ | 지배적 레버. 기본 0.5는 무의미, 운영점 0.8~0.95 |
| 프롬프트 v1→v2 | real 칩에선 유효 개선 (F1 0.76→0.80). **mask 칩에선 무이득** — v1/v2/C/C2 동률(0.76~0.79), τ 가 지배 (§6) |
| 인코딩 (whole / A1 / C2) | whole-image CLS 가 최선. A1·C2 는 개선 없음/실패 |
| 칩 (mask / context / real) | real 이 v2 와 궁합. context 는 과발화 |
| 백본 (B/32 / L/14) | 잔격자는 평균 풀링엔 독, max 풀링엔 약이나 코사인 압축이 그대로 |

**현재 최선**: v1 CLS + v2 프롬프트 + real 칩 + τ≈0.85 → P 0.78 / R 0.82 / F1 0.80.

**한계**: 재현율 천장 ~0.82. 고대비 전환(관통도로·태양광·비닐하우스·건물·신선 나지)은 잡히나,
저대비 전환(벌채 후 재식생 풀밭·묘지·오래된 나지)은 단일 시점 겨울 RGB로 구분 불가.
→ 다시점 변화탐지 · 경사도/DEM · 허가·현장 데이터 필요.
